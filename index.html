01Como usar e o que priorizar

Abra o tópico pelo menu e toque em C ou Java. Cada bloco de código é um programa independente e completo, com exemplo de uso no main. Não junte todos no mesmo arquivo.

02Complexidade: Θ, O e Ω

Primeiro escolha a operação relevante: comparações entre dados, adições, subtrações ou chamadas da função pedida. Não conte automaticamente todas as linhas.

ConceitoExemplo
Função exataT(n) = 3n² + 5n + 2
Ordem justaΘ(n²): o termo quadrático domina
Limite superiorO(n²) e O(n³) são válidos; O(n) não
Limite inferiorΩ(n) e Ω(n²) são válidos; Ω(n³) não

O não significa automaticamente pior caso; Ω não significa melhor caso. Escolha o caso e depois descreva o crescimento. Os limites admitem constantes e valem para n suficientemente grande.

CrescimentoExemplo típico
Θ(1)Uma operação constante
Θ(log n)Índice dividido por 2 até parar
Θ(n)Uma varredura
Θ(n log n)n passagens com trabalho logarítmico
Θ(n²)Dois laços de n aninhados
Θ(n³)Três laços de n aninhados

Lista 1, 5(b): 500n + 100n1,5 + 50n log₁₀n tem ordem Θ(n1,5). O termo dominante deve existir na função; não escolha n² só porque apareceu numa tabela.

03Somatórios: reconhecer e resolver

Σ significa somar. O índice indica a passagem; a expressão à direita indica quanto será somado em cada passagem.

Σ de i=1 até 5 de 1 = 1+1+1+1+1 = 5
Σ de i=1 até 5 de i = 1+2+3+4+5 = 15
SomaForma fechada
Σ de i=a até b de cc(b − a + 1), para inteiros a ≤ b
Σ de i=0 até n de in(n+1)/2
Σ de i=0 até n−1 de in(n−1)/2
Σ de i=0 até n de i²n(n+1)(2n+1)/6
Σ de i=0 até n de i³[n(n+1)/2]²
Σ de i=0 até n de qⁱ(qⁿ⁺¹−1)/(q−1), q ≠ 1

Limites: 0…n tem n+1 termos; 0…n−1 tem n termos; 1…n tem n termos. Constante sai multiplicando. Soma de expressões pode ser separada.

Lista 1 — 1(a)
Σ(3i+4), i=0…n
= 3Σi + 4(n+1)
= 3n(n+1)/2 + 4(n+1)
= (3n²+11n+8)/2 → Θ(n²)
Lista 1 — 1(b)
(2i+3)² = 4i²+12i+9
Σ, i=0…n−1
= 4(n−1)n(2n−1)/6 + 12n(n−1)/2 + 9n
= (4n³+12n²+11n)/3 → Θ(n³)

Aqui Θ classifica o crescimento da soma. O custo de calcular uma fórmula fechada é outra pergunta.

04Do for ao somatório + log

Exemplo estudado nos slides: procurar o menor faz uma comparação por passagem de i=1 até n−1. T(n)=Σ1=n−1. Não é Gauss, porque o termo somado é 1, não i.

for (int i = 1; i < n; i++) {
    if (min > array[i]) min = array[i];
}

Lista 1, questão 10 — contar subtrações:

for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
        b = b - 1;
        c--;
    }
    d = c - d;
}
Para cada i: 2i + 1 subtrações.
T(n)=Σ(2i+1), i=0…n−1
= 2[n(n−1)/2] + n = n².
Para n=5: 1+3+5+7+9=25.

Logaritmo: para n inteiro ≥1, o laço for (int i=n; i>1; i/=2) executa ⌊log₂n⌋ vezes. Se faz 3 chamadas por passagem, T(n)=3⌊log₂n⌋. Se há uma chamada fora, some 1. Se um laço externo repete isso n vezes, multiplique por n.

Laços separados: somam custos. Laços aninhados: some o custo interno para cada passagem externa; só multiplique diretamente quando esse custo for igual em todas as passagens.

05Indução: prova passo a passo

Base → hipótese → próximo termo → fórmula para k+1. Você não troca tudo aleatoriamente: usa a hipótese apenas na soma anterior.

Gauss: S(n)=1+2+…+n=n(n+1)/2

Base n=1: 1=1(2)/2.
Hipótese: S(k)=k(k+1)/2.
Passo: S(k+1)=S(k)+(k+1)
= k(k+1)/2 + (k+1)
= [k(k+1)+2(k+1)]/2
= (k+1)(k+2)/2.
É a fórmula com n=k+1. Logo vale para todo n≥1.
Questão 10: T(n)=Σ(2i+1), i=0…n−1=n²
Base n=1: 1=1².
Hipótese: T(k)=k².
Novo termo: i=k → 2k+1.
T(k+1)=k²+2k+1=(k+1)².
Lista 1, 1(a) e 2:
S(n)=Σ(3i+4), i=0…n
Fórmula: (3n²+11n+8)/2.
Base n=0: 4=8/2.
Hipótese: S(k)=(3k²+11k+8)/2.
Novo termo: 3(k+1)+4=3k+7.
S(k+1)=(3k²+17k+22)/2.
A fórmula em k+1 produz o mesmo resultado.

Erro a evitar: 2k+1 era o novo ímpar. Para Gauss, o próximo termo é k+1. Cada sequência tem seu próprio novo termo.

06Lista em vetor — inserir, remover e pesquisar

Insere na posição abrindo espaço à direita; remove fechando o espaço à esquerda. n é quantidade usada; CAP é capacidade. Inserir/remover início ou meio: O(n); final: O(1). Código completo adaptado.

Códigos completos · C / Java

Programa independente · programa.c

#include <stdio.h>
#include <stdlib.h>

#define CAP 100

void erro(void) {
    fprintf(stderr, "Operacao invalida ou sem memoria\n");
    exit(EXIT_FAILURE);
}
void imprimir(int x) { printf("%d ", x); }
void linha(void) { printf("\n"); }

int array[CAP];
int n = 0;

void inserir(int x, int pos) {
    if (n == CAP || pos < 0 || pos > n) erro();
    for (int i = n; i > pos; i--)
        array[i] = array[i - 1];
    array[pos] = x;
    n++;
}
void inserirInicio(int x) { inserir(x, 0); }
void inserirFim(int x) { inserir(x, n); }
int remover(int pos) {
    if (pos < 0 || pos >= n) erro();
    int x = array[pos];
    for (int i = pos; i < n - 1; i++)
        array[i] = array[i + 1];
    n--;
    return x;
}
int removerInicio(void) { return remover(0); }
int removerFim(void) { return remover(n - 1); }
int pesquisar(int x) {
    for (int i = 0; i < n; i++)
        if (array[i] == x) return i;
    return -1;
}
void mostrar(void) {
    for (int i = 0; i < n; i++) imprimir(array[i]);
    linha();
}

int main(void) {
    inserirFim(7);
    inserirInicio(2);
    inserir(5, 1);
    mostrar(); // 2 5 7
    imprimir(remover(1)); linha(); // 5
    mostrar(); // 2 7
    return 0;
}

09Fila circular em vetor

primeiro = próxima remoção; ultimo = próxima inserção. Nesta convenção reservamos uma posição: CAP posições guardam CAP−1 dados. O módulo faz voltar ao início. Não desloca valores; ambas operações são O(1).

Vazia: primeiro == ultimo
Cheia: (ultimo+1) % CAP == primeiro
Códigos completos · C / Java

Programa independente · programa.c

#include <stdio.h>
#include <stdlib.h>

#define CAP 100

void erro(void) {
    fprintf(stderr, "Operacao invalida ou sem memoria\n");
    exit(EXIT_FAILURE);
}
void imprimir(int x) { printf("%d ", x); }
void linha(void) { printf("\n"); }

int array[CAP];
int primeiro = 0, ultimo = 0;

void inserir(int x) {
    if ((ultimo + 1) % CAP == primeiro) erro();
    array[ultimo] = x;
    ultimo = (ultimo + 1) % CAP;
}
int remover(void) {
    if (primeiro == ultimo) erro();
    int x = array[primeiro];
    primeiro = (primeiro + 1) % CAP;
    return x;
}
void mostrar(void) {
    for (int i = primeiro; i != ultimo; i = (i + 1) % CAP)
        imprimir(array[i]);
    linha();
}

int main(void) {
    inserir(10); inserir(20); inserir(30);
    imprimir(remover()); linha(); // 10
    inserir(40);
    mostrar(); // 20 30 40
    return 0;
}

Cabeça é uma célula auxiliar. Não conta como dado. Primeiro dado = primeiro.prox (Java) ou primeiro->prox (C). Em lista/fila com cabeça, vazio significa primeiro == ultimo.

11Pilha encadeada sem cabeça

topo aponta para o último inserido. Vazia: topo == NULL/null. Inserção e remoção O(1).

Códigos completos · C / Java

Programa independente · programa.c

#include <stdio.h>
#include <stdlib.h>

#define CAP 100

void erro(void) {
    fprintf(stderr, "Operacao invalida ou sem memoria\n");
    exit(EXIT_FAILURE);
}
void imprimir(int x) { printf("%d ", x); }
void linha(void) { printf("\n"); }

typedef struct Celula {
    int elemento;
    struct Celula *prox;
} Celula;
Celula *topo = NULL;

Celula *novaCelula(int x) {
    Celula *p = malloc(sizeof(Celula));
    if (p == NULL) erro();
    p->elemento = x;
    p->prox = NULL;
    return p;
}
void inserir(int x) {
    Celula *nova = novaCelula(x);
    nova->prox = topo;
    topo = nova;
}
int remover(void) {
    if (topo == NULL) erro();
    Celula *retirada = topo;
    int x = retirada->elemento;
    topo = retirada->prox;
    free(retirada);
    return x;
}
void mostrar(void) {
    for (Celula *i = topo; i != NULL; i = i->prox)
        imprimir(i->elemento);
    linha();
}
void liberar(void) {
    while (topo != NULL) remover();
}

int main(void) {
    inserir(10); inserir(20); inserir(30);
    imprimir(remover()); linha(); // 30
    mostrar(); // 20 10
    liberar();
    return 0;
}

12Fila encadeada com cabeça

A remoção avança a cabeça: a célula do dado removido vira a nova cabeça. O valor dela deixa de contar. Em C, libera a cabeça antiga, não a nova. Inserção/remoção O(1).

Códigos completos · C / Java

Programa independente · programa.c

#include <stdio.h>
#include <stdlib.h>

#define CAP 100

void erro(void) {
    fprintf(stderr, "Operacao invalida ou sem memoria\n");
    exit(EXIT_FAILURE);
}
void imprimir(int x) { printf("%d ", x); }
void linha(void) { printf("\n"); }

typedef struct Celula {
    int elemento;
    struct Celula *prox;
} Celula;
Celula *primeiro, *ultimo;

Celula *novaCelula(int x) {
    Celula *p = malloc(sizeof(Celula));
    if (p == NULL) erro();
    p->elemento = x;
    p->prox = NULL;
    return p;
}
void iniciar(void) {
    primeiro = novaCelula(0);
    ultimo = primeiro;
}
void inserir(int x) {
    ultimo->prox = novaCelula(x);
    ultimo = ultimo->prox;
}
int remover(void) {
    if (primeiro == ultimo) erro();
    Celula *antiga = primeiro;
    primeiro = primeiro->prox;
    int x = primeiro->elemento;
    antiga->prox = NULL;
    free(antiga);
    return x;
}
void mostrar(void) {
    for (Celula *i = primeiro->prox; i != NULL; i = i->prox)
        imprimir(i->elemento);
    linha();
}
void liberar(void) {
    while (primeiro != ultimo) remover();
    free(primeiro);
    primeiro = ultimo = NULL;
}

int main(void) {
    iniciar();
    inserir(10); inserir(20); inserir(30);
    imprimir(remover()); linha(); // 10
    mostrar(); // 20 30
    liberar();
    return 0;
}

13Lista simples COMPLETA + ordenações

Cabeça fixa nesta lista. Inclui inserir início/fim/posição, remover início/fim/posição, mostrar, liberar, inserirOrdenado, Selection, Bubble, Insertion e Shellsort.

Inserção ordenada ≠ Insertion Sort: inserirOrdenado exige que a lista já esteja ordenada; insercao organiza uma lista desordenada. As ordenações alteram valores, não ligações. Selection/Bubble/Insertion são adaptações nossas e usam apenas prox.

    return removerCelula(ultimo);
}
// Exige lista previamente ordenada.
static void inserirOrdenado(int x) {
    Celula a = primeiro;
    while (a.prox != null && a.prox.elemento < x)
        a = a.prox;
    Celula nova = novaCelula(x);
    nova.ant = a;
    nova.prox = a.prox;
    if (a.prox != null) a.prox.ant = nova;
    else ultimo = nova;
    a.prox = nova;
    n++;
}
static void insercao() {
    if (n < 2) return;
    for (Celula i = primeiro.prox.prox;
         i != null; i = i.prox) {
        int tmp = i.elemento;
        Celula j = i.ant;
        while (j != primeiro && j.elemento > tmp) {
            j.prox.elemento = j.elemento;
            j = j.ant;
        }
        j.prox.elemento = tmp;
    }
}
static Celula avancar(Celula p, int h) {
    while (p != null && h > 0) { p = p.prox; h--; }
    return p;
}
static Celula recuar(Celula p, int h) {
    while (p != null && h > 0) { p = p.ant; h--; }
    if (p == primeiro) return null;
    return p;
}
static void shellsort() {
    if (n < 2) return;
    int h = 1;
    do { h = 3*h + 1; } while (h < n);
    do {
        h /= 3;
        for (int cor = 0; cor < h; cor++) {
            Celula inicio = avancar(primeiro.prox, cor);
            for (Celula i = avancar(inicio, h);
                 i != null; i = avancar(i, h)) {
                int tmp = i.elemento;
                Celula destino = i;
                Celula j = recuar(i, h);
                while (j != null && j.elemento > tmp) {
                    destino.elemento = j.elemento;
                    destino = j;
                    j = recuar(j, h);
                }
                destino.elemento = tmp;
            }
        }
    } while (h != 1);
}
static void mostrarReverso() {
    for (Celula i = ultimo; i != primeiro; i = i.ant)
        imprimir(i.elemento);
    linha();
}

public static void main(String[] args) {
    iniciar();
    inserirFim(3); inserirFim(4);
    inserirFim(1); inserirFim(5);
    mostrar(); // 3 4 1 5
    insercao(); // Ou selecao(), bolha(), shellsort().
    mostrar(); // 1 3 4 5
    inserirOrdenado(2);
    mostrar(); // 1 2 3 4 5
    imprimir(removerInicio()); linha(); // 1
    mostrarReverso(); // 5 4 3 2
    liberar();
}
}

}
void insercao(void) {
    for (int i = 1; i < n; i++) {
        int tmp = array[i], j = i - 1;

            array[j + h] = array[j]; j -= h;

    if (n < 2) return;

    do { h = 3*h + 1; } while (h < n);
    do {
        h /= 3;
        for (int cor = 0; cor < h; cor++) insercaoPorCor(cor, h);
    } while (h != 1);
}
void quicksort(int esq, int dir) {
    if (esq >= dir) return;
    int i = esq, j = dir;
    int pivo = array[esq + (dir - esq)/2];
    while (i <= j) {
        while (array[i] < pivo) i++;
        while (array[j] > pivo) j--;
        if (i <= j) { swap(i, j); i++; j--; }
    }
    quicksort(esq, j); quicksort(i, dir);
}
void mergesort(int esq, int dir) {
    if (esq >= dir) return;
    int m = esq + (dir - esq)/2;
    mergesort(esq, m); mergesort(m + 1, dir);
    int i = esq, j = m + 1, k = esq;
    while (i <= m && j <= dir) {
        if (array[i] <= array[j]) aux[k++] = array[i++];
        else aux[k++] = array[j++];
    }
    while (i <= m) aux[k++] = array[i++];
    while (j <= dir) aux[k++] = array[j++];
    for (k = esq; k <= dir; k++) array[k] = aux[k];
}
// Heap com indices comecando em ZERO nesta adaptacao.
void descer(int tam, int i) {
    int maior = i, e = 2*i + 1, d = 2*i + 2;
    if (e < tam && array[e] > array[maior]) maior = e;
    if (d < tam && array[d] > array[maior]) maior = d;
    if (maior != i) { swap(i, maior); descer(tam, maior); }
}
void heapsort(void) {
    for (int i = n/2 - 1; i >= 0; i--) descer(n, i);
    for (int fim = n - 1; fim > 0; fim--) {
        swap(0, fim); descer(fim, 0);
    }
}
// Versao simples: valores inteiros de 0 ate CAP-1.
void countingSort(void) {
    int cont[CAP];

    for (int i = 0; i < n; i++) {
        if (array[i] < 0 || array[i] >= CAP) erro();
        cont[array[i]]++;
    }
    int pos = 0;
    for (int valor = 0; valor < CAP; valor++)
        for (int q = 0; q < cont[valor]; q++) array[pos++] = valor;
}
// Radix decimal: somente inteiros nao negativos.
void radixsort(void) {
    int maior = 0;
    for (int i = 0; i < n; i++) {
        if (array[i] < 0) erro();
        if (array[i] > maior) maior = array[i];
    }
    for (int div = 1; maior / div > 0; ) {
        int cont[CAP];
        for (int d = 0; d < 10; d++) cont[d] = 0;
        for (int i = 0; i < n; i++) cont[(array[i]/div)%10]++;
        for (int d = 1; d < 10; d++) cont[d] += cont[d-1];
        // Da direita para a esquerda: mantem estabilidade.
        for (int i = n - 1; i >= 0; i--) {
            int d = (array[i]/div)%10;
            aux[--cont[d]] = array[i];
        }
        for (int i = 0; i < n; i++) array[i] = aux[i];
        if (div > maior/10) break; // Evita overflow.
        div *= 10;
    }
}

    for (int i = 0; i < n; i++) imprimir(array[i]);
    linha();
}

16Pesquisas e recursividade

Sequencial retorna índice ou −1. Binária exige ordem crescente. Recursão: caso base + problema menor; cada chamada tem seus parâmetros. Soma/fatorial abaixo recebem n não negativo; fatorial limitado a 12 para caber em int de 32 bits.

#include <stdio.h>
#include <stdlib.h>

#define CAP 100

void erro(void) {
    fprintf(stderr, "Operacao invalida ou sem memoria\n");

}
void imprimir(int x) { printf("%d ", x); }
void linha(void) { printf("\n"); }

int array[CAP];
int n;

int sequencial(int x) {
    for (int i = 0; i < n; i++)
        if (array[i] == x) return i;
    return -1;
}
int binaria(int x) {
    int esq = 0, dir = n - 1;
    while (esq <= dir) {
        int m = esq + (dir - esq)/2;
        if (array[m] == x) return m;
        if (x > array[m]) esq = m + 1;
        else dir = m - 1;
    }
    return -1;
}
int soma(int n) {
    if (n < 0) erro();
    if (n == 0) return 0;
    return n + soma(n - 1);
}
int fatorial(int n) {
    if (n < 0 || n > 12) erro();
    if (n == 0) return 1;
    return n * fatorial(n - 1);
}

    imprimir(binaria(12)); linha(); // 3
    imprimir(soma(3)); linha(); // 6
    imprimir(fatorial(4)); linha(); // 24
    return 0;
}
